# 项目说明

## 1. 项目是什么

这是一个面向临床文书重复性操作的自动化原型。

项目核心不是开发通用办公自动化工具，而是探索如何将医疗场景中的复杂重复任务拆解为：

> 原子操作 + OCR/信息提取 + 文本处理 + 工作流

并通过桌面端软件进行组织和执行。

---

## 2. 为什么采用这种方案

实际业务界面存在结构复杂、页面交互固定、文本显示相对稳定等特点。

因此项目没有完全依赖通用OCR，而是尝试结合：

- 图像预处理
- 特定颜色提取
- 模板/位图匹配
- OCR
- 规则处理
- 工作流执行

以降低某些受控场景下的实现复杂度。

---

## 3. 项目主要模块

### 用户界面

负责：

- 任务展示
- 工作流配置
- 工作流编排
- OCR调试
- 硬件控制
- 执行日志

### 工作流

负责：

- 原子步骤执行
- 条件分支
- 工作流状态管理
- 多个工作流之间的编排

### OCR

负责：

- 页面内容识别
- 行检测
- 字符识别
- 特定显示环境适配

### 文本处理

负责：

- 识别结果清洗
- 表格解析
- 字段提取
- 规则匹配
- 结构化输出

### 硬件

负责：

- 屏幕采集
- 键盘模拟
- 鼠标模拟
- 帧缓存
- 文件传输

---

## 4. 项目当前定位

本项目为个人研究与作品集项目。
